# Melhorar prompt

## Quando usar
O usuario pediu para melhorar, refinar ou orientar um prompt — para si mesmo, para outro agente ou para geracao de midia.

## Procedimento
1. Entenda a intencao real do prompt original: o que o usuario quer alcancar, para quem e, em que formato.
2. Use o orientador de prompt do app (canal `orientar:prompt`) quando disponivel.
3. Preserve a intencao central — melhorar nao e mudar o objetivo.
4. Adicione o que falta: contexto, restricoes, formato de saida, publico-alvo, tamanho, exemplos.
5. Remova ambiguidade: troque termos vagos por especificos ("bom" -> criterio concreto).
6. Entregue o prompt reescrito pronto para copiar, mais 1-2 frases explicando o que mudou.

## Criterio de sucesso
- O prompt melhorado produziria uma resposta visivelmente melhor que o original.
- A intencao original esta preservada e reconhecivel.

## O que NAO fazer
- Nao alongar o prompt sem agregar criterio.
- Nao mudar o objetivo do pedido original.
- Nao incluir instrucoes que o modelo de destino nao entenderia.

# Modo gratuito

## Quando usar
O usuario pediu explicitamente modo free/gratuito/local, ou nenhum provider pago esta configurado.

## Procedimento
1. Prefira modelos locais via Ollama — nao gastam credito nem quota.
2. Use os agentes free (Coder Free, Debugger Free, Reviewer Free etc.) quando o pedido combinar com a especialidade.
3. Se o modelo local nao estiver instalado, liste os instalados (`ollama` via terminal ou `/api/tags`) e use o melhor disponivel.
4. Para tarefas pesadas que o local nao da conta, diga o custo estimado antes de usar provider pago.
5. Responda em portugues do Brasil e seja pratico — sem enrolacao.

## Criterio de sucesso
- Nenhum custo pago foi gerado sem o usuario saber.
- A resposta veio de provider local/free ou o motivo da excecao foi explicado.

## O que NAO fazer
- Nao usar provider pago silenciosamente em modo free.
- Nao baixar modelo grande sem avisar (ocupa GB de disco e RAM).
- Nao prometer qualidade de frontier model com modelo local pequeno — seja honesto sobre limites.

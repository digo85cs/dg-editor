# Editor

## Quando usar
Editar e salvar arquivos abertos na aba Editor.

## Procedimento
1. O Editor tem quebra de linha automática.
2. Salve com Ctrl+S ou o botão Salvar da barra.
3. O fim de linha original (CRLF/LF) é preservado ao gravar.
4. Após apply de proposta do agente, a aba reabre o arquivo do disco.

## Critério de sucesso
- O conteúdo na tela bate com o arquivo salvo.
